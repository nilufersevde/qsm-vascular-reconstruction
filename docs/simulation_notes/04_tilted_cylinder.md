
# Simulation 04 — Tilted Cylindrical Vessel Phantom

## 1. Objective

Extend the original cylindrical susceptibility phantom to support
different vessel orientations relative to the main magnetic field
$B_0$.

This implementation provides a foundation for investigating the
relationship between vessel orientation, dipole inversion, and
quantitative susceptibility reconstruction accuracy.

## 2. Mathematical formulation

The original cylindrical phantom is aligned with the z-axis.

For a cylinder tilted by an angle $\theta$ in the x-z plane,
the unit vector describing its axis is:

$$
\mathbf{u} = (\sin\theta, 0, \cos\theta)
$$

For a spatial point $\mathbf{r}=(x,y,z)$, the squared perpendicular
distance from the cylinder axis is:

$$
d_\perp^2 =
\|\mathbf{r}\|^2 -
(\mathbf{r}\cdot\mathbf{u})^2
$$

Expanding this expression gives:

$$
d_\perp^2 =
x^2+y^2+z^2 -
(x\sin\theta+z\cos\theta)^2
$$

An equivalent formulation is:

$$
d_\perp^2 =
y^2+(x\cos\theta-z\sin\theta)^2
$$

A voxel belongs to the cylindrical vessel when its center satisfies:

$$
d_\perp^2 \leq R^2
$$

## 4. Geometry validation

### 4.1 Zero-degree orientation

At zero degrees, the perpendicular distance reduces to:

$$
d_\perp^2 = x^2+y^2
$$

The tilted-cylinder implementation must therefore reproduce
the original z-aligned cylindrical phantom.

An exact voxel-by-voxel comparison confirmed that the two
susceptibility arrays were identical.

### 4.2 Ninety-degree orientation

At ninety degrees, the perpendicular distance reduces to:

$$
d_\perp^2 = y^2+z^2
$$

The expected reference phantom was generated by exchanging
the x and z axes of the original cylindrical phantom:

```python
chi_expected = np.swapaxes(chi_original, 0, 2)
```

This reference was compared with the tilted-cylinder
implementation using an exact array comparison.

## 5. Floating-point precision

The initial ninety-degree validation identified six mismatched
voxels located on the mathematical cylinder boundary.

This discrepancy arose from floating-point arithmetic.
In particular, the numerical evaluation of the cosine of
ninety degrees is not exactly zero.

The original distance formulation also involved subtraction
of potentially large, nearly equal quantities, introducing
the risk of numerical cancellation.

The distance calculation was therefore replaced with:

```python
d_perp_squared = (
    Y**2
    + (X * np.cos(theta) - Z * np.sin(theta))**2
)
```

Although this formulation avoids subtractive cancellation,
the ninety-degree test still identified 261 mismatched voxels
due to floating-point errors in boundary classification.

A small radius-dependent numerical tolerance was introduced:

```python
tolerance = 1e-12 * radius**2

vessel_mask = d_perp_squared <= radius**2 + tolerance
```

For the default vessel radius of 5 mm, this corresponds
to a squared-distance tolerance of 2.5e-11 mm².

The tolerance is a numerical implementation parameter,
not a physical modeling parameter.

Following this correction, both orientation tests passed
using exact array comparisons.

## 7. Current limitations

- Vessel rotation is restricted to the x-z plane.
- The cylinder is effectively infinite and truncated by
  the computational volume.
- Voxel occupancy is binary.
- Partial-volume effects are not explicitly modeled.
- Arbitrary orientations have not yet been independently
  validated.
- Forward-field calculations for tilted vessels have not
  yet been validated.

In particular, tilted cylinders may introduce boundary
artifacts when used with FFT-based forward modeling,
which assumes periodic boundary conditions.
